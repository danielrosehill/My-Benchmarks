A browsable index of Daniel Rosehill's benchmarks and evals. The page reads
[`benchmarks.json`](https://github.com/danielrosehill/My-Benchmarks/blob/master/benchmarks.json)

Source: `space/` in [danielrosehill/My-Benchmarks](https://github.com/danielrosehill/My-Benchmarks).
